# 仪表盘卡片库

可添加的卡片由 `dashboard-catalog.ts` 配置：

- `kind: 'route'`：填写已注册的 `destination`（路由名和该路由允许的参数），生成页面快捷入口。标题默认读取路由翻译，不重复硬编码 URL。
- `kind: 'module'`：填写来源路由 `source`，并传入一个能独立渲染的 Vue `component`。先把所需区域从页面提取成可复用组件，不要把整个路由页面作为模块挂载。现有例子是「当前主题色板」，语义配色页与看板共用同一个组件。
- `kind: 'builtin'`：选择现有时钟、便签、入口组、图表等面板类型与默认配置。

每项都有稳定的 `id`和宽／窄布局尺寸；标题及说明可使用本地化消息。改标题或渲染组件时不要改 ID，否则已摆放的卡片找不到对应配置。

卡片库、可添加范围、个人布局是三件事。布局继续通过现有存储接口保存，包括两套位置和每张卡的配置；移除一个注册项不会让整份布局失效。将来接管理端时，可以把 API 返回的允许 ID 与本地注册表取交集后交给添加入口。API 不提供 Vue 实现或任意跳转 URL；页面和数据访问权限仍由项目的实际鉴权流程检查。
